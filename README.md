# Gravity Indoor Trampoline Park Website

A modern, responsive Flutter web application for Gravity Indoor Trampoline Park. This site is designed to showcase the park's activities, party packages, play parks, and escape rooms in an engaging, interactive way.

## Features

- **Responsive Design**: Fully responsive layout that works on mobile, tablet, and desktop screens
- **Modern UI**: Clean, modern interface with smooth animations and parallax effects
- **Interactive Elements**: Engaging interactive components to improve user experience
- **Brand-Consistent**: Uses the Gravity brand colors (#F36122, #000000, #87C540, #FFFFFF) throughout

## Sections

- **Home**: Overview of the park with key highlights and testimonials
- **Activities**: Details on all available activities and pricing
- **Parties**: Party packages and booking information
- **Play Parks**: Information about different play park locations
- **Escape Rooms**: Themed escape room experiences
- **Contact**: Contact form and business information

## Getting Started

1. Ensure you have Flutter installed and set up for web development
2. Clone this repository
3. Run `flutter pub get` to install dependencies
4. Run `flutter run -d chrome` to launch the app in Chrome

## Dependencies

- `flutter_animate`: For smooth animations and transitions
- `responsive_framework`: For responsive layout management
- `go_router`: For navigation between pages
- `card_swiper`: For interactive card swiping components
- `google_fonts`: For typography
- `url_launcher`: For launching URLs, phone calls, and emails
- `font_awesome_flutter`: For social media and other icons
